## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-08-01 | Info Disclosure | credentials in logs/cache | mitigate | store only `self._auth` (base64); never log/cache user/password; cache payload contains only public fields (uid, legal_form, status, ehraid-derived URL) |
| T-08-02 | Tampering | source_url echoed from response | mitigate | construct source_url from integer `ehraid` to a fixed `zefix.admin.ch/de/search/entity/{ehraid}/info` path — never copy a URL field from the JSON |
| T-08-03 | Tampering | name injection into request body | mitigate | `requests.post(json=body)` auto-encodes JSON; no string interpolation; name length-guarded (≥3) |
| T-08-04 | Denial of Service | malformed/oversized response crashes row | mitigate | `_parse` wraps all access in try/except (KeyError/TypeError) → None; `lookup`/`_request` never raise; per-run `_Budget` caps total calls |
| T-08-05 | Tampering | path traversal via cache key | accept | `cache.key_for()` is sha256 hexdigest (verified safe, T-05-02) — no new exposure |
| T-08-06 | Repudiation | wrong attribution from ambiguous match | mitigate | `_parse` returns None unless exactly 1 result; >1 → "nicht gefunden", never first-of-list (AC5) |
