## Aggregation spec (pin EXACTLY — [CITED: docs/scoring_website_bedarf.md + 03-RESEARCH.md])
Step 0 dead override (highest priority): if `any(v.dead for v in verdicts)` → return 5. Stop.
Step 1 points: `ok=0, gap=1, severe=2`.
Step 2: `G = sum(points)`, `S = count(level=="severe")` over ALL passed verdicts (Dim 3 placeholder is "ok" = 0, harmless).
Bands:
| Condition | Score |
|---|---|
| any verdict dead | 5 |
| G >= 7 OR S >= 3 | 5 |
| 4 <= G <= 6 OR S == 2 | 4 |
| 2 <= G <= 3 OR S == 1 | 3 |
| G == 1 | 2 |
| G == 0 | 1 |
Tie-break: compute both a G-band score and an S-band score and `return max(...)` → guarantees monotonicity (AC3/BED-08).

_POINTS = {"ok": 0, "gap": 1, "severe": 2}


def bedarf(verdicts: list[DimensionVerdict]) -> int:
    """Deterministische 6-Dimensionen-Aggregation -> 1..5 (BED-07/08).

    dead-Override (keine/defekte Website) hat höchste Priorität (-> 5). Sonst
    Gap-Punkte G + Severe-Anzahl S -> Bänder gemäss docs/scoring_website_bedarf.md.
    Tie-Break = max(G-Band, S-Band) -> monoton (AC3): jede zusätzliche Lücke kann
    den Score nur heben oder halten.
    """
    if any(v.dead for v in verdicts):
        return 5
    G = sum(_POINTS[v.level] for v in verdicts)
    S = sum(1 for v in verdicts if v.level == "severe")
    g_score = 5 if G >= 7 else 4 if G >= 4 else 3 if G >= 2 else 2 if G == 1 else 1
    s_score = 5 if S >= 3 else 4 if S == 2 else 3 if S == 1 else 1
    return max(g_score, s_score)
```

def build(verdicts: list[DimensionVerdict]) -> str:
    """Kompakte, nachvollziehbare Begründung (NACH-01/AC6) aus den 6 Befunden.

    Listet nur die nicht-ok Dimensionen mit Befund-Level + Reason; hängt die
    aus genau denselben Verdicts berechnete Bedarf-Note an, damit Score und Text
    nie auseinanderlaufen. Auf ~200 Zeichen gekappt.
    """
    score = scoring.bedarf(verdicts)
    drivers = [v for v in verdicts if v.level != "ok" or v.dead]
    if not drivers:
        return f"alle Dimensionen ok → Bedarf {score}"
    _label = {"severe": "schwere Lücke", "gap": "Lücke"}
    parts = [
        f"Dim{v.dim} {_label.get(v.level, v.level)} ({v.reason})"
        for v in drivers
    ]
    body = "; ".join(parts)
    summary = f" → Bedarf {score}"
    budget = 200 - len(summary)
    if len(body) > budget:
        body = body[: max(0, budget - 1)].rstrip() + "…"
    return body + summary
```
