## Sub-signal → dimension combination rule (Pattern 2, applies to BOTH dims, pin EXACTLY)
Classify each sub-signal as one of: `severe` / `gap` / `minor`. Then fold:
- **any** sub-signal `severe` → dimension = `"severe"`
- else **≥1** `gap` → dimension = `"gap"`
- else **≥2** `minor` → dimension = `"gap"`
- else → `"ok"`

The reason string = a compact German join of the firing (non-ok) sub-signal notes. If all ok, a short positive note.
